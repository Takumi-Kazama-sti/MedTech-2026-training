# 出退勤アプリ
## 状態遷移図

``` mermaid
  flowchart TD
  %% アクター
  employee((従業員))
  
  %% 従業員の状態
  NotWork[未出勤]
  Working[勤務中]
  Breaking[休憩中]
  Ended[退勤済み]
  

  %% 従業員の状態遷移
  employee --> NotWork
  NotWork -- 打刻：出勤 --> Working
  Working -- 打刻：休憩開始 --> Breaking
  Breaking -- 打刻：休憩終了 --> Working
  Working -- 打刻：退勤 --> Ended
  Ended --> NotWork

```
